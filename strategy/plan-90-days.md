# План на первые 90 дней (менторский чек-лист)

*Старт: 16.11.2026. Совет директоров отмечает прогресс каждый понедельник. ✋ — делает человек, 🤖 — делают агенты.*

## С чего начать на этой неделе (самое важное)

1. ✋ **Решить позиционирование:** согласны ли вы с флагманом «лазерные и оптические измерительные системы + электроника как вход» ([стратегия, п. 2](strategy.md))? Это ключевое решение, от него зависит всё остальное.
2. ✋ **Проверить платёжный путь:** спросить в Приорбанке и Технобанке, из каких стран и в каких валютах реально проходят платежи для ИП за инженерные услуги; узнать о валютном контроле.
3. ✋ **Консультация юриста и бухгалтера (1–2 часа):** ООО или ИП, лимит найма для ИП, ПВТ, налоги на экспорт услуг, требования к сайту (хостинг в РБ).
4. ✋ **Фотосъёмка:** список кадров готовит 🤖 «Маркетолог».
5. 🤖 **Первые 50 потенциальных заказчиков** по флагманской нише в РБ, РФ и Казахстане (агент «Охотник», расписание: вт).

## Недели 1–2: решения и фундамент
- [ ] ✋ Утвердить флагман, продукты-входы и стартовые цены
- [ ] ✋ Консультация юриста и бухгалтера → решение по ООО и ПВТ
- [ ] ✋ Банки: два валютных счёта, ответы о платежах из разных стран
- [ ] 🤖 Шаблоны: NDA, рамочный договор + задание, акт, change request (RU/EN) → ✋ проверка юристом
- [ ] 🤖 Тексты для сайта: новые кейсы (по вашим ответам), страница команды, «Производство», «Комплаенс»
- [ ] ✋ Ответить агенту на вопросы по каждому из 6 кейсов: цифры, сроки, страна, что можно раскрыть
- [ ] 🤖 Профиль идеального заказчика (ICP) по каждой нише
- [ ] ✋ Выбрать домены; 🤖 подготовить варианты хостинга

- [ ] ✋ Публикация сайта; 🤖 Search Console, Вебмастер, аналитика
- [ ] 🤖 PDF-презентация компании (RU/EN)

- [ ] 🤖 Профили в каталогах: Clutch, GoodFirms, HardwareBee
- [ ] ✋ Начать активные продажи: 20–30 персональных сообщений в неделю по черновикам 🤖
