# Воронка заказчиков: правила

## Профиль идеального заказчика (ICP), версия 1

| Ниша | Кто заказчик | Сигналы потребности |
|---|---|---|
| **Лазерные и оптические измерения, метрология, неразрушающий контроль** (флагман) | Металлургия, прокат, трубы, автокомпоненты, станкостроение, железная дорога, энергетика; ОТК и метрологические службы заводов; НИИ и лаборатории | Новый цех или линия, модернизация, проблемы с качеством или браком, тендер на измерительную систему, вакансия «инженер-метролог» или «инженер по автоматизации контроля», переход на импортозамещение измерительного оборудования |
| **Электроника и печатные платы** (вход) | Hardware-стартапы, производители приборов без своего схемотехника, интеграторы, IoT-компании | Привлечены инвестиции, анонсирован новый продукт, вакансия «hardware engineer / PCB designer» открыта долго, найм в R&D |
| **Стенды испытаний и автоматизация контроля** | Производители датчиков, электроники, автокомпонентов, пищевые производства | Рост выпуска, сертификация, жалобы на качество, тендеры на стенды |
| **Наука и уникальные приборы** | Университеты, НИИ, лаборатории, научные стартапы | Гранты, тендеры на научное оборудование, публикации о новых установках |

**Регионы (волна 1):** Беларусь (вкл. парк «Великий камень»), Россия, Казахстан, Узбекистан, Китай (как партнёры), ОАЭ, Турция, Индия, Сербия. **Волна 2:** ЕС и США — только проекты без контролируемых технологий.

**Не берём:** военные и силовые структуры, оборонные предприятия, компании из санкционных списков ЕС, США, Великобритании, Канады; проекты с неясным конечным использованием.

## Где искать
- Сайты и новости компаний, отраслевые СМИ (новые заводы, линии, модернизация).
- Тендеры: zakupki.gov.ru (223-ФЗ, 44-ФЗ), B2B-Center, «Фабрикант», icetrade.by и goszakupki.by (РБ), goszakup.gov.kz (КЗ).
- Списки экспонентов выставок: Иннопром, «Фотоника», «Металлообработка», выставки по неразрушающему контролю, ExpoElectronica; Control, VISION, Automatica, LASER World of PHOTONICS (для волны 2).
- Базы стартапов и акселераторов: Сколково, ФРИИ, НТИ; Crunchbase и новости о раундах (hardware).
- Вакансии (hh.ru, LinkedIn): компания долго ищет схемотехника, метролога или инженера по автоматизации.
- Резиденты индустриального парка «Великий камень».

## Оценка
- **A** — сильный сигнал + точное попадание в нишу + понятный путь к ЛПР. Писать в ближайшую неделю.
- **B** — подходит, сигнал слабее или нет понятного контакта. В план на месяц.
- **C** — потенциально интересно, наблюдать.

## Поля таблицы `leads.md`
| Поле | Что писать |
|---|---|
| Дата | Когда добавлен |
| Компания | Название + сайт |
| Страна | |
| Ниша | Из профиля выше |
| Сигнал | Что именно говорит о потребности, кратко |
| Источник | Ссылка на сигнал |
| Кому писать | Роль (и публичный профиль, если есть). Без личных телефонов и адресов |
| Оценка | A / B / C |
| Санкц. проверка | «чисто (opensanctions, дата)» или причина отказа |
| Статус | новый → черновик письма → отправлено (человеком) → ответ → встреча → предложение → пилот → контракт / отказ |
