# Штаб COLLIMA Engineering

Мультиагентная система, которая помогает запустить и развивать COLLIMA Engineering: исследует рынок, ищет заказчиков, готовит маркетинг, продажи, юридические и производственные материалы. Раз в неделю проводит «совет директоров».

**Табло агентов:** https://claude.ai/artifact/Q9QjooKzaKc98Yh65iiVXB (закреплено в боковой панели claude.ai)

## Как устроено
| Папка | Что внутри |
|---|---|
| `CLAUDE.md` | Правила для всех агентов |
| `company/` | Профиль компании |
| `strategy/` | Стратегия и план |
| `reports/` | Исследования и разборы |
| `ops/board/` | Протоколы совета директоров |
| `ops/tasks.md` | Доска задач по отделам |
| `ops/leads/` | Воронка потенциальных заказчиков |
| `ops/drafts/` | Черновики писем, постов, текстов сайта, договоров |
| `ops/inbox.md` | **Ваши поручения совету** |
| `ops/procedures/` | Процедуры запусков по расписанию |
| `.claude/agents/` | 18 агентов: роли, модели, инструкции |
| `dashboard/` | Исходник табло |
| `agent.py` | Локальный агент на Claude Agent SDK (основа для будущего Telegram-бота) |

## Расписание
- **Пн 08:52 (Минск):** совет директоров + рабочий цикл отделов
- **Вт 09:52 (Минск):** поиск потенциальных заказчиков

Работает в облаке, компьютер владельца не нужен.

## Локальный агент (`agent.py`)
Для запуска со своего компьютера или сервера:
```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...   # оплачивается по токенам, отдельно от подписки
python agent.py "Проанализируй конкурентов в нише лазерной метрологии"
```
Агент читает профиль компании из `company/profile.md`.
