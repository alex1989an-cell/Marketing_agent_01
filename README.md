# Маркетинговый агент

AI-агент на [Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk), который:

- анализирует конкурентов и тренды в интернете;
- составляет контент-планы и пишет посты, рассылки, рекламу;
- помогает с SEO: ключевые слова, структура статей, мета-теги;
- сохраняет результаты в папку `output/`, а посты — в таблицу `output/content_plan.csv`.

Внутри главный агент и три подагента-специалиста: **researcher** (исследования), **copywriter** (тексты) и **seo**.

## Быстрый старт

1. Установите Python 3.10+ и Node.js 18+ (SDK использует Claude Code под капотом).
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Получите API-ключ на [console.anthropic.com](https://console.anthropic.com) и задайте его:
   ```bash
   export ANTHROPIC_API_KEY=sk-ant-...
   ```
4. **Заполните `brand.md`**: компания, аудитория, тон, конкуренты. Это самый важный шаг.
5. Запустите:
   ```bash
   # одна задача
   python agent.py "Проанализируй конкурентов и составь контент-план для Telegram на 2 недели"

   # диалог с агентом
   python agent.py
   ```

## Примеры задач

- «Сделай анализ трёх главных конкурентов: что они публикуют, какие у них цены, где их слабые места»
- «Напиши 5 постов для Instagram про наш новый продукт и добавь их в контент-план»
- «Составь цепочку из 3 приветственных писем для новых подписчиков»
- «Подбери ключевые слова и структуру статьи для блога на тему …»
- «Придумай 10 идей для рекламной кампании к Новому году»

## Настройка

| Что | Где |
|---|---|
| Данные о бизнесе | `brand.md` |
| Модель | переменная `MARKETING_AGENT_MODEL` (по умолчанию `claude-opus-5-5`; дешевле — `claude-sonnet-5-5`) |
| Поведение главного агента | `build_system_prompt()` в `agent.py` |
| Подагенты (добавить, изменить) | словарь `SUBAGENTS` в `agent.py` |
| Свои инструменты | декоратор `@tool` в `agent.py` (пример — `add_to_content_plan`) |

## Идеи для развития

- Инструмент публикации в Telegram через Bot API.
- Подключение Google Analytics или рекламных кабинетов для отчётов.
- Запуск по расписанию, например еженедельный отчёт по понедельникам.
